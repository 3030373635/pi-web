# Chrome 103 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 隔离 Chrome 103 回退并提供 Windows Actions 浏览器回归。

**Architecture:** 共享 CSS 值转换器供 PostCSS 和源码 loader 使用。入口脚本仅安装浏览器缺少的能力，CSS 覆盖集中于兼容目录。

**Tech Stack:** Next.js、PostCSS、Lightning CSS、Playwright、Windows GitHub Actions。

**Spec:** docs/superpowers/specs/2026-11-03-chrome-103-design.md

## Global Constraints

- 不自动提交 Git；不在本地运行生产构建；测试使用 Windows Actions。
- 新函数附中文用途及参数注释。仅必要入口修改上游文件。

## Review Focus

- 长对话滚轮确实移动，输入框保持可见，窗口缩放后布局正常。
- 主题切换及延迟加载的样式、动态内联颜色仍能更新。
- 设置各页、选择框、文件树及弹窗在短窗口可滚动。
- 现代浏览器继续使用原生 CSS，不触发观察器循环。
- CI 核验真实浏览器版本，不用 User-Agent 伪装旧浏览器。
